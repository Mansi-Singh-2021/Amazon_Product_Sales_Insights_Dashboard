# Amazon Product Sales Insights Dashboard

## About the Project

This project is an interactive Power BI dashboard created to analyze Amazon product sales data and transform raw data into meaningful business insights.

The main goal of this dashboard is to help understand:
- how different product categories are performing,
- which products generate the highest profit,
- where opportunity loss occurs,
- and how sales and returns vary across countries.

While building this project, I focused not only on data visualization but also on creating an interactive and user-friendly dashboard experience.



# Dashboard Highlights

✨ Interactive KPI Cards  
✨ Dynamic Profit & Opportunity Loss Analysis  
✨ Custom Filter Navigation Panel  
✨ Year and Month Slicers  
✨ Country-wise Sales Insights  
✨ Product Category & Sub-category Analysis  
✨ DAX Measures and Calculated Columns  
✨ Modern Dark-Themed Dashboard Design  



# Data Model / Schema Design

- Product Subcategories

The schema was designed to support efficient filtering, DAX calculations, and interactive dashboard analysis.

# Features Included

## 1. KPI Analysis
The dashboard contains KPI cards to quickly track:
- Total Profit
- Total Orders
- Total Returns

These KPIs help users understand overall business performance at a glance.



## 2. Category & Sub-category Insights
I used:
- Treemap Visuals
- Bar Charts

to analyze order distribution across different categories and sub-categories.

This helps identify:
- best-performing categories,
- highly ordered products,
- and weak-performing segments.



## 3. Dynamic Profit & Opportunity Loss Toggle
One of the most interactive parts of the dashboard is the custom toggle feature.

Using buttons, bookmarks, and DAX measures, users can switch dynamically between:
- Profit Analysis
- Opportunity Loss Analysis

This makes the dashboard more interactive and improves the overall user experience.



## 4. Interactive Filter Panel
I created a custom filter panel that opens using the Amazon logo button.

The filter panel includes:
- Month slicer
- Year slicer
- Value selection options

This allows users to explore the dashboard dynamically based on different conditions.



## 5. Country-wise Analysis
The map visualization helps analyze:
- total orders,
- total profit,
- and return rate by country.

This provides geographical insights into sales performance.
